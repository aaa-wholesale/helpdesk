⚠ How to fix Mail.Send:

  • Go to portal.azure.com → Azure Active Directory → App Registrations
  • Open your HelpDesk Pro app → API Permissions
  • Click Add a permission → Microsoft Graph → Delegated
  • Search for Mail.Send → Add permission
  • Click Grant admin consent for your tenant
  • Come back and click Test Connection again
